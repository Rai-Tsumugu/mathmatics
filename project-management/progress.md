## 更新ルール

- ステータスは `未着手` / `作業中` / `レビュー中` / `完了` / `保留` を使用する。
- 単元の総合進捗は4教材の完了度を目安に、25%刻みで更新する。
- 担当者・期限・課題は「メモ」へ記載する。大きな課題はIssueへ分離する。
- このファイルは初回同期時のみ生成され、以後の `npm run content:sync` では上書きされない。
- **正本の分担（2026-07-29決定）**: このファイルは「全体工程」「リリース判定」「執筆順」の
  正本である。単元・問題・レビューの制作状態の正本は `src/content/admin-data.json`
  （管理画面）であり、下の単元別表は節目にのみ反映する概況ビューとする。
  将来は P17 で自動生成に切り替える。
